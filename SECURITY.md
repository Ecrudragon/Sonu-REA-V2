# Security policy

## Scope

Security reports are welcome for this repository's site and project configuration. Do not submit APKs, secrets, personal data, or details about a third-party system that you are not authorized to assess.

## Reporting a vulnerability

Use GitHub's Report a vulnerability option on the repository's Security tab to send a private report. If that option is unavailable, contact the repository owner privately through their GitHub profile. Include the affected file or workflow, impact, and safe steps to reproduce. Do not publish sensitive details in a public issue or pull request.

Please allow time for review and coordinated remediation before public disclosure. This project does not make a response-time guarantee.
