Stage 1 / 7

Step 1.1: Install Genuine Termux & Toolchain

Never install Termux from Google Play Store (it is outdated and repository updates will abort). Install strictly from F-Droid or GitHub Releases. Then run this one-line toolchain installer:

termux-setup.sh 
pkg update && pkg upgrade -y
termux-setup-storage
pkg install openjdk-17 jadx apktool aapt nodejs apksigner git -y

When Android requests storage permission, tap Allow.

Step 2.1: Locate and Pull Base APK

Installed apps live in /data/app/. Their base packages are world-readable on standard Android without root:

extract-apk.sh 
# 1. Query path for target package (e.g., com.target.app)
pm path com.target.app

# 2. Copy the resulting path to your Download folder
cp /data/app/~~.../base.apk ~/storage/shared/Download/target.apk

Alternative: Use ML Manager from F-Droid to export any app to your storage in 1 click.

Step 3.1: Dual Disassembly (Smali & Java)

Apktool creates the editable workspace, while JADX decompiles bytecode into readable Java logic:

decompile.sh 
# 1. Apktool workspace for editing Smali & Resources
cd ~/storage/shared/Download
apktool d target.apk -o target_workspace

# 2. JADX Java source view for reading algorithms
jadx -j 2 --no-res -d java_view target.apk

Step 5.1: Modify Smali Instructions & Assets

Open Acode Editor (Free on F-Droid) or run nano in Termux to edit files inside ~/storage/shared/Download/target_workspace:

.method public isLicensed()Z
    .registers 2
    const/4 v0, 0x0
    return v0
.end method
// AFTER (Patched to Return True):

    .registers 2

Step 6.1: Recompile with AAPT2 & 4-Byte Zipalign

Reassemble your workspace into an APK and enforce 4-byte boundary page-alignment (required by Android 11+ runtime):

rebuild-align.sh 
cd ~/storage/shared/Download
# 1. Compile into unsigned APK
apktool b target_workspace -o unsigned.apk --use-aapt2

# 2. 4-byte memory boundary alignment
zipalign -p -f -v 4 unsigned.apk aligned.apk

Step 7.1: Keystore Generation & V2/V3 Signing

Generate your local RSA key and apply APK Signature Scheme V2/V3 using apksigner:

sign-install.sh 
# 1. Generate local keystore (one time only)
keytool -genkey -v -keystore release.jks -alias sonu_key -keyalg RSA -keysize 2048 -validity 10000 -storepass password123 -keypass password123 -dname "CN=SonuREA, OU=Dev, O=Sonu, C=IN"

# 2. Sign with APK V2/V3 full signature scheme
apksigner sign --ks release.jks --ks-pass pass:password123 --out ready_to_install.apk aligned.apk

# 3. Trigger native Android package installation
termux-open ready_to_install.apk
⚠️ Crucial: Uninstall the original application from your device first, as the cryptographic signatures will not match.

Field-Tested Troubleshooting Matrix

App is an App Bundle (.apks / Split APKs)

Pass all extracted splits together into Apktool simultaneously:
apktool d base.apk -o out/

Termux Process Killed [OOM]

Multi-dex archives exceed RAM. Constrain parallel worker threads:
jadx -j 1 --no-res -d out/ target.apk
